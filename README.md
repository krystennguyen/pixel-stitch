# Pixel Stitch

A pattern editor for cross-stitch and crochet projects. Design stitch patterns from scratch or convert any photo into a color-mapped grid.

**Live site:** https://krystennguyen.github.io/pixel-stitch

---

## Features

- **Pattern grid** — draw on an interactive canvas with pencil, fill bucket, and eraser tools
- **Image to pattern** — upload a photo and automatically convert it to a stitch grid using k-means color quantization
- **Photo overlay** — trace over your reference image directly on the canvas with adjustable opacity
- **Color palette** — custom palette with up to any number of colors; add, delete, and select swatches
- **Show / hide stitches** — toggle stitch symbols (X / crochet) on or off for a clean color-block view
- **Zoom** — resize cells from 4 px to 48 px with a slider or +/− buttons
- **Grid size** — set custom width and height up to 200 × 200
- **Export PNG** — save the current grid as a PNG image
